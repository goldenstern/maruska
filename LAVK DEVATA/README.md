# LAVK DEVATA — структура проекта

Оркестратор LAVK: понимает новые задачи, ведёт и докладывает статусы через рантайм `dev_console`, работает с Основателем по гейтам.

```text
pipeline-setup/                     корень проекта

LAVK DEVATA/                        скилл и политика оркестратора
    SKILL.md                        правила, гейты, фан-аут
    PIPELINE_PROJECT_TEMPLATE.md    шаблон контекста проекта
    README.md                        эта карта

DEV_CONSOLE/                        локальный OpenCode-плагин
    index.ts                        адаптер OpenCode, события, диспатч, HTTP-канал
    state.ts                        модель состояния, ledger, операции и UI-проекция
    server_guard.ts                 реестр серверов и FIFO-очередь на проект
    cpu.ts                          CPU-гейт и мониторинг
    personas.ts                     каталог ипостасей
    experience.ts                   межпроектный опыт
    activity.ts                     активность и заголовки вкладок
    ritual.ts                       ночной/послеволновый ритуал
    import_gate.ts                  статическая сверка локальных импортов/экспортов
    *.test.ts                       тесты модулей

DEVATA/                             локальные runtime-артефакты (не публиковать)
    state.json                      канонический ledger
    CONSOLE_UI.html                 запечённая проекция панели
    DEV_CONSOLE_RUNTIME_ARCHITECTURE.md
                                    архитектурный контракт
```

## Принцип разделения

- **SKILL = политика и взаимодействие.**
- **RUNTIME = исполняемая правда.** Состояние, допустимые переходы, координация и проекция не должны зависеть от того, что модель «помнит» из промпта.
- **UI = проекция ledger.** Панель отображает состояние, но не является его источником.
- `DONE` терминален; переделка = новая задача.

## Проверка

Полный локальный набор тестов и импорт-гейт:

```powershell
npm run check
```

Отдельно:

```powershell
npm run test
npm run gate
```

## Запуск и защита рантайма

Плагин загружается при старте процесса OpenCode; **hot-reload нет**. Изменения исходников проверяются тестами и import-gate. Применение к живому рантайму требует нового процесса OpenCode и отдельного разрешения Основателя на деплой. Не перезапускать сервис и не редактировать `DEVATA/state.json` / `DEVATA/CONSOLE_UI.html` вручную.

Приватные runtime-файлы `DEVATA/*`, ключи и локальные настройки не копировать в публичные репозитории.
