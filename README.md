# Маруська · Корпорация Ясность

**LAVK DEV CONSOLE** — фреймворк-консоль для [OpenCode](https://opencode.ai): панель рантайма, где по репо работают **инстансы** (Маруська и ребята), ведут реестр задач, помнят всё в леджере и докладывают своему оператору — без облаков, всё локально.

> Одна машина — один Сотрудник Корпорации Ясность. Каждый деплой — своя вселенная: свой сервер, свой леджер, свои инстансы, и Сотрудник там — тот, кто за этой машиной сидит. Инстансы не путают операторов и не смешивают репо.
>
> Титул **Папы** у Корпорации один — GoldenStern, автор фреймворка. Его не носят на чужих машинах.

## Что умеет

- 🛰 **Панель** (`DEVATA/CONSOLE_UI.html`) — живой вид рантайма: инстансы (статус, модель, бар задач), очередь, чат, диаги. Авто-обновление, канал записи, кнопка гашения экранов.
- ⚡ **Реестр задач** — конечный автомат `WAIT · DOING · BLOCKED · GATE · DONE` в леджере (`DEVATA/state.json`), атомарная запись + rolling-бэкап, восстановление из гита (RECOVERY).
- 🧝 **Ипостаси** (`DEV_CONSOLE/personas.ts`) — каталог персонажей: Маруська Гольденштерн (координация), Мара, Мария Кюри, Магдалена… модель выбирает ипостась при спавне и держит до конца сессии. Имя местное и неприкосновенное, неизвестное имя не выдумывается.
- 🤖 **Диспатч и дети** — субагенты-исполнители с выбором модели по классу, кулдауны, fallback на резерв, квоты, грейс активных сессий.
- 🧠 **Память** — `DEVATA/AGENT_CHAT.md` (лента инцидентов и декретов), ночной/послеволновый ритуал памяти, протокол деплоя «Семь Я» (`docs/PROTOCOL-7Y.md`).
- 🛡 **Безопасность** — защита от перегруза (CPU-гейт ~70%/90%), write-exclusive (одна живая сессия на задачу), no service restarts, пароли только в `service.json` (в гит не попадают).

## Установка

Нужен [OpenCode](https://opencode.ai) 2.x (Node ≥ 20 / Bun).

**Ленивый путь (корпоративный стандарт):** скопируй промпт из
[docs/INSTALL_PROMPT.md](docs/INSTALL_PROMPT.md) в свежий сеанс OpenCode —
он сам склонирует, подключит, проверит сьют, познакомится и откроет панель.
От тебя — имя и слово «запускай».

Ручной путь:

```bash
git clone https://github.com/goldenstern/maruska.git
cd maruska
npm install
```

### 1. Зарегистрировать плагин (обязательный шаг!)

OpenCode грузит плагины из каталога `~/.config/opencode/plugins/`. Сделайте джанкен/симлинк на `DEV_CONSOLE` из клона:

**Windows (PowerShell, без админа):**

```powershell
New-Item -ItemType Junction `
  -Path "$env:USERPROFILE\.config\opencode\plugins\dev-console" `
  -Target "<путь-к-клону>\maruska\DEV_CONSOLE"
```

**macOS / Linux:**

```bash
mkdir -p ~/.config/opencode/plugins
ln -s <путь-к-клону>/maruska/DEV_CONSOLE ~/.config/opencode/plugins/dev-console
```

### 2. Подключить скилл

В конфиге OpenCode (`~/.config/opencode/opencode.json` или проектном):

```json
{
  "model": "<твоя модель>",
  "skills": ["<путь-к-клону>/maruska/LAVK DEVATA"]
}
```

### 3. Перезапустить OpenCode

Перезапуск — и в каждом гит-репо при первом сеансе появится папка `DEVATA/`:
леджер (`state.json`), панель (`CONSOLE_UI.html`), лента (`AGENT_CHAT.md`).
Это и есть память репо.

- Рантайм сам читает адрес и пароль твоего OpenCode-сервера из
  `~/.local/state/opencode/service.json` (или legacy `~/.config/opencode/service.json`)
  — ничего вписывать не надо.
- Скилл **LAVK DEVATA** — правила работы: понять заказ, записать в реестр,
  работать, верифицировать, гейтить решения оператора.

## Правило разделения

- **Сотрудник Корпорации Ясность** (сотрудница — если так) — оператор своей машины/сервера. Только он/она гейтит деплой, токены и решения своего деплоя.
- **Папа** — титул одного человека: GoldenStern, автор фреймворка. К операторам чужих деплоев не применяется.
- **Ребята** — инстансы репо (top-вкладки) и дети-исполнители (детские сессии). Дети — исполнители, не инстансы.
- Сессии/леджеры/панели **не пересекаются между машинами**; адрес сервера — локальный.

## Структура

```
DEV_CONSOLE/        рантайм: state.ts (ядро+леджер), index.ts (крючья OpenCode),
                    personas.ts (ипостаси), cpu.ts (гейт нагрузки), тесты (node:test)
LAVK DEVATA/        скилл оркестратора: SKILL.md, README, шаблон проекта
docs/               PROTOCOL-7Y.md — церемониальный протокол деплоя
```

## Тесты

```bash
node --experimental-strip-types --test DEV_CONSOLE/state.test.ts
```

Сьют держит каноны реестра, статусов вкладок, грейсов и гашения экранов.

## Диагностика

Если Маруська молчит или `DEVATA/` не появилась — запусти доктора из корня клона:

```bash
node scripts/doctor.mjs
```

Он проверит: регистрацию плагина (джанкен/симлинк), резолв зависимости `@opencode/plugin`,
скилл в `opencode.json`, наличие `DEVATA` в текущем репо и версию OpenCode —
и подскажет точный фикс по каждой пометке ✘.

## Апдейты

Сей репо — публичное зеркало: канонический источник правды — рабочий деплой Корпорации; апдейты качаются сюда после волн (`scripts/sync-from-pipeline.ps1`), свежее — по тегам.

### v0.2.0 · 17.11 — Прочность леджера и наблюдаемость агентов
- **CAS/merge при сохранении леджера** — конец гонке целофайловых перезаписей (устаревший снимок больше не терёт свежие записи);
- **межпроцессный sidecar-аллокатор ID** `T###/A###` (`state.json.ids.json`, свой файл-лок, fail-closed) — дублей номеров больше нет;
- **наблюдаемость детей**: `op=progress` (самоотчёт исполнителя по своей сессии), per-agent tokens/cost, `REQ` по уникальным завершённым сообщениям, last tool + reconnect/resync истории (V1/V2 transcript);
- **декрет «Папа один»** + знакомство с овнером машины при первом запуске (имя помнится в `~/.config/opencode/LAVK_OWNER.md`);
- сьют 340/340, import-gate чистый.

### v0.2.1 · 17.11 — Гашение экранов v2
- `/monitors-off` бьёт адресно в окно рабочего стола (Progman ×3 + WorkerW) вместо broadcast — HWND_BROADCAST после ребута перестал доносить импульс сквозь зависшие окна; проба Основателем подтверждена.

### v0.2.2 · 17.11 — Предохранитель диспатча и чистая панель
- **капа ретраев на ПОПЫТКИ** (≥5 спавнов задачи за час, любое состояние) + **авто-BLOCKED** задачи при исчерпании — шторм «17 мёртвых детей за 38 минут» невозможен: дети, умершие молча (сессия создана, исполнения нет), больше не ослепляют капу;
- **панель схлопывает спящих детей**: 2 последние строки + сводная «▸ ×N спящих» вместо простыни одинаковых;
- `/monitors-off` зовёт коммиченный `DEV_CONSOLE/scripts/monitors_off.ps1` через `-File` (инлайн `-Command` хрупок; v2: Progman ×3 + WorkerW);
- дисциплина исполнителя в SKILL: ручной ретрай ≤2, дальше доклад.

### v0.2.3 · 17.11 — хотфикс: спавн моники-кнопки
- `/monitors-off` спавнит скрипт через **`spawnDetached` (`shell:true`)** — проверенный путь, которым поднят панель-сервер: прямой `spawn("powershell", …, {detached})` в рантайме сервиса молча не рождал процесс (замер: powershell до/после POST — 4/4), кнопка отвечала «ok», а экраны стояли;
- спавн не состоялся → честный **500**, в ответе — pid.

### v0.2.4 · 17.11 — гашение без окна
- `/monitors-off` зовёт **user32 нативно** (`bun:ffi`, Progman ×3 + WorkerW): ни дочернего процесса, ни мигающего окна консоли; фолбэк — `spawnDetached` для не-bun рантаймов;
- панель: спящие дети старше 2 минут — только сводной строкой «▸ ×N спящих», мёртвые проекции фида больше не захламляют вкладку.
