# Маруська · Корпорация Ясность

**LAVK DEV CONSOLE** — фреймворк-консоль для [OpenCode](https://opencode.ai): панель рантайма, где по репо работают **инстансы** (Маруська и ребята), ведут реестр задач, помнят всё в леджере и докладывают Папе — без облаков, всё локально.

> Одна машина — один Папа. Каждый деплой — своя вселенная: свой сервер, свой леджер, свои инстансы, и Папа там — тот, кто за этой машиной сидит. Инстансы не путают Пап и не смешивают репо.

## Что умеет

- 🛰 **Панель** (`DEVATA/CONSOLE_UI.html`) — живой вид рантайма: инстансы (статус, модель, бар задач), очередь, чат, диаги. Авто-обновление, канал записи, кнопка гашения экранов.
- ⚡ **Реестр задач** — конечный автомат `WAIT · DOING · BLOCKED · GATE · DONE` в леджере (`DEVATA/state.json`), атомарная запись + rolling-бэкап, восстановление из гита (RECOVERY).
- 🧝 **Ипостаси** (`DEV_CONSOLE/personas.ts`) — каталог персонажей: Маруська Гольденштерн (координация), Мара, Мария Кюри, Магдалена… модель выбирает ипостась при спавне и держит до конца сессии. Имя местное и неприкосновенное, неизвестное имя не выдумывается.
- 🤖 **Диспатч и дети** — субагенты-исполнители с выбором модели по классу, кулдауны, fallback на резерв, квоты, грейс активных сессий.
- 🧠 **Память** — `DEVATA/AGENT_CHAT.md` (лента инцидентов и декретов), ночной/послеволновый ритуал «папа, а мы…», протокол деплоя «Семь Я» (`docs/PROTOCOL-7Y.md`).
- 🛡 **Безопасность** — защита от перегруза (CPU-гейт ~70%/90%), write-exclusive (одна живая сессия на задачу), no service restarts, пароли только в `service.json` (в гит не попадают).

## Установка

Нужен [OpenCode](https://opencode.ai) 2.x (Node ≥ 20 / Bun).

```bash
git clone https://github.com/goldenstern/maruska.git
cd maruska
npm install
```

### 1. Зарегистрировать плагин (обязательный шаг!)

OpenCode грузит плагины из каталога `~/.config/opencode/plugins/`. Сделайте джанкен/симлинк на `DEV_CONSOLE` из клона:

**Windows (PowerShell, без админа):**

```powershell
New-Item -ItemType Junction `
  -Path "$env:USERPROFILE\.config\opencode\plugins\dev-console" `
  -Target "<путь-к-клону>\maruska\DEV_CONSOLE"
```

**macOS / Linux:**

```bash
mkdir -p ~/.config/opencode/plugins
ln -s <путь-к-клону>/maruska/DEV_CONSOLE ~/.config/opencode/plugins/dev-console
```

### 2. Подключить скилл

В конфиге OpenCode (`~/.config/opencode/opencode.json` или проектном):

```json
{
  "model": "<твоя модель>",
  "skills": ["<путь-к-клону>/maruska/LAVK DEVATA"]
}
```

### 3. Перезапустить OpenCode

Перезапуск — и в каждом гит-репо при первом сеансе появится папка `DEVATA/`:
леджер (`state.json`), панель (`CONSOLE_UI.html`), лента (`AGENT_CHAT.md`).
Это и есть память репо.

- Рантайм сам читает адрес и пароль твоего OpenCode-сервера из
  `~/.local/state/opencode/service.json` (или legacy `~/.config/opencode/service.json`)
  — ничего вписывать не надо.
- Скилл **LAVK DEVATA** — правила работы: понять заказ, записать в реестр,
  работать, верифицировать, гейтить решения Папы.

## Правило разделения

- **Папа** — оператор машины/сервера. Только он гейтит деплой, токены и решения.
- **Ребята** — инстансы репо (top-вкладки) и дети-исполнители (детские сессии). Дети — исполнители, не инстансы.
- Сессии/леджеры/панели **не пересекаются между машинами**; адрес сервера — локальный.

## Структура

```
DEV_CONSOLE/        рантайм: state.ts (ядро+леджер), index.ts (крючья OpenCode),
                    personas.ts (ипостаси), cpu.ts (гейт нагрузки), тесты (node:test)
LAVK DEVATA/        скилл оркестратора: SKILL.md, README, шаблон проекта
docs/               PROTOCOL-7Y.md — церемониальный протокол деплоя
```

## Тесты

```bash
node --experimental-strip-types --test DEV_CONSOLE/state.test.ts
```

Сьют держит каноны реестра, статусов вкладок, грейсов и гашения экранов.
